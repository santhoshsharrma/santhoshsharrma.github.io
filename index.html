How I build

I started in Computer Science with a Data Science specialization — a lot of statistics, a lot of analysis. Somewhere along the way I got more interested in the systems that move and serve data than the data itself, and that pulled me toward backend engineering.

I prefer explicit, script-driven workflows: command line over GUI, version control I can read, code I can trace step by step. If I can't explain why something works, I don't consider it finished. Outside of the stack, I spend time thinking about design — how interfaces, decisions, and even code structure should be built around how people actually use and understand them.
